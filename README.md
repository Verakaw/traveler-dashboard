# Voyager — дашборд путешественника

Адаптивное приложение на чистом JavaScript с ES Modules. В нём пять независимых виджетов: прогноз Open-Meteo, карточка страны REST Countries, конвертер Frankfurter, локальный список вещей и таймер до поездки. Карточки можно добавлять, сворачивать и удалять; их локальные данные сохраняются в `localStorage`.

## Запуск локально

Не открывайте `index.html` напрямую как `file://`: браузеры блокируют загрузку ES Modules и API-запросы для файлового origin, поэтому интерфейс и обработчики не запустятся. Откройте папку любым статическим сервером. Например, если установлен Python:

```bash
python -m http.server 8000
```

Перейдите на `http://localhost:8000`. Также подойдут Live Server или любой статический хостинг.

## Публикация на GitHub Pages

1. Создайте GitHub-репозиторий и добавьте в него содержимое этой папки (путь `index.html` должен быть в корне публикуемой директории).
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, затем ветку `main` и папку `/ (root)`; нажмите **Save**.
4. После завершения сборки сайт будет доступен по адресу `https://<username>.github.io/<repository>/`.

Сборка не нужна. Пути к скриптам и стилям относительные, поэтому приложение работает и в подпути GitHub Pages. Для собственного домена его можно настроить в том же разделе Pages.

## API и доступность

- Погода: геокодинг `geocoding-api.open-meteo.com`, затем прогноз `api.open-meteo.com`. Авторизация не нужна. В погодном виджете есть обязательная ссылка-атрибуция Open-Meteo.
- Страны: `restcountries.com/v3.1/name/...` с ограничением полей. Авторизация не нужна; запросы выполняются прямо из браузера.
- Валюты: Frankfurter API (`api.frankfurter.dev/v2/rate/{from}/{to}`), данные Европейского центрального банка, без ключа. Конвертация суммы вычисляется по полученному курсу.

### Важное замечание о REST Countries

На 1 октября 2026 года прежние endpoint-ы REST Countries v1–v4 отключены; сам сервис сообщает, что новый v5 требует регистрации и Bearer API key. Чтобы сохранить работу без ключа, виджет сначала пробует исходный REST Countries v3.1, затем при сетевой ошибке или ответе о депрекации загружает открытый список стран из репозитория `mledoze/countries` на GitHub и ищет по названию, ISO alpha-2/alpha-3 коду или региону. Открытый raw endpoint проверен с HTTP 200 и `Access-Control-Allow-Origin: *`. Это статический резервный источник, поэтому поиск не требует регистрации.

Проверка endpoint-ов подтвердила HTTP 200 и `Access-Control-Allow-Origin: *` для Open-Meteo geocoding и резервного списка стран; Frankfurter `/v2/rate/USD/EUR` также ответил 200. Open-Meteo forecast ранее возвращал валидный прогноз, хотя последняя прямая проверка из среды разработки завершилась таймаутом. Доступность зависит от текущего состояния сервисов и сети; виджеты показывают состояния загрузки, сетевую ошибку, таймаут и пустой результат.

## Архитектура

- `js/UIComponent.js` — абстрактная оболочка: регистрация слушателей, таймеров и запросов, сворачивание и полная очистка.
- `js/Dashboard.js` — `Map` экземпляров, фабрика виджетов и делегирование действий контейнеру.
- `js/services/ApiService.js` — JSON `fetch`, таймаут и отмена через `AbortController`.
- `js/widgets/` — изолированные реализации виджетов.
- `styles/` — оформление тёмной темы и адаптивной CSS Grid-сетки.

Список вещей и поездка хранятся локально в браузере. API-виджеты не требуют ключей и не отправляют пользовательские данные, кроме введённых поисковых запросов.
